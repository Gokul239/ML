# 📈 Time Series Forecasting on Sales Data

## 🧠 Project Overview

This project performs **time series forecasting** on a monthly sales dataset. The analysis involves preprocessing, stationarity testing, decomposition, and building predictive models using classical statistical approaches such as **ARIMA**.

---

## 📊 Objectives

- Analyze sales time series data for trend, seasonality, and noise.
- Test and transform the data to make it stationary.
- Build forecasting models using statistical techniques (ARIMA).
- Evaluate model performance on a test dataset.
